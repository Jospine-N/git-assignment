&#x20;**Git Assignment**



* &#x20;**Purpose**

This assignment demonstrates how to use Git, VS Code, and GitHub to manage and track changes in a project.



1. &#x20;*How I will use Git*

I will use Git to:

\- Initialize a repository using git init

\- Track changes in files using git add

\- Save versions of my work using git commit

\- Check the status of my project using git status



2\. *How I will use VS Code*

I will use Visual Studio Code to:

\- Create and edit files such as README.md

\- Write and organize my project content

\- Use the integrated terminal to run Git commands



3\. *What this assignment demonstrates about GitHub*

This assignment shows:

\- How to upload a local project to GitHub

\- How GitHub stores and tracks project versions online

\- How version control helps manage changes and collaboration
